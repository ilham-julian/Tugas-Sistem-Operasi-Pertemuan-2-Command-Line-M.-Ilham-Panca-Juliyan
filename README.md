# Tugas-Sistem-Operasi-Pertemuan-2-Command-Line-M.-Ilham-Panca-Juliyan

Penjelasan dari 50 command:

1. pwd: Menampilkan direktori kerja saat ini (*print working directory*).
2. ls: Menampilkan daftar berkas dan folder di direktori saat ini.
3. whoami: Menampilkan nama pengguna yang sedang aktif.
4. id: Menampilkan ID pengguna (UID) dan ID grup (GID).
5. w: Menampilkan siapa saja yang sedang login dan aktivitas mereka.
6. date: Menampilkan tanggal dan waktu sistem saat ini.
7. uptime: Menampilkan durasi sistem telah berjalan sejak *booting*.
8. hostname: Menampilkan nama *host* atau nama komputer di jaringan.
9. uname: Menampilkan informasi tentang sistem operasi dan kernel.
10. alias: Menampilkan atau membuat pintasan nama untuk perintah terminal.
11. tty: Menampilkan nama perangkat terminal (*teletype*) yang sedang digunakan oleh sesi kamu saat ini (misalnya `/dev/pts/0`). 
12. arch: Menampilkan arsitektur perangkat keras (misal: x86_64).
13. echo Hello World!: Mencetak teks "Hello World!" ke layar terminal.
14. printf: Format dan cetak teks atau data ke terminal (mirip perintah echo, namun dengan kontrol format yang lebih akurat seperti pada bahasa pemrograman C).
